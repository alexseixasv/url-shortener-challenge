# Frontend agent

Antes de implementar:

- Consulte o README e ADRs relevantes.
- Respeite os contratos definidos pela API.

Ao alterar o frontend:

- Não duplique regras de negócio que pertencem ao backend.
- Priorize funcionalidade sobre complexidade visual.
- Evite dependências sem necessidade clara.
- Quando houver telas com dados, trate loading, erro e estados vazios.
